# awesome-web-app-design(日本語)

[English README](README.md)

美しい Web デザイン・アプリデザインのための無料リソースを厳選し、継続的に更新しているリストです — グラフィック、フォント、カラー、アイコン、ストック素材、CSS フレームワーク、アニメーション、UI コンポーネント、デザインシステム、デザインツール、インスピレーション、AI 向けデザインファイル。

セクション構成は [Brad Traversy の design-resources-for-developers](https://github.com/bradtraversy/design-resources-for-developers)(MIT ライセンス)に倣っています。同リストは 2026年10月18日に新規リソースの受け付けを停止しました。本リストは各セクションから項目を絞って選び、移転・改名したリンクを更新し、アーカイブされたプロジェクトを外したうえで、新しいツールを追加し続けます。

⭐ バッジは GitHub のスター数をリアルタイム表示します(shields.io)。release バッジは GitHub の最新リリース日(YYYY/MM/DD、最終更新時点)を示します。last commit バッジは最新コミット日をリアルタイム表示します(shields.io)。

## UI グラフィック

UI 向けのイラスト、パターン、アバター、背景ジェネレーター。

- [Humaaans](https://www.humaaans.com/) - パーツを組み合わせて作れる人物イラスト集。
- [unDraw](https://undraw.co/) - アクセントカラーを変えられるオープンソースの SVG イラスト集。
- [Open Peeps](https://www.openpeeps.com/) - 手描きの人物イラストライブラリ(CC0)。
- [Open Doodles](https://www.opendoodles.com/) - ラフな手描き風イラストの無料セット。
- [Blush](https://blush.design/) - 多数のアーティストによるカスタマイズ可能なイラスト。Figma プラグインあり。
- [IRA Design](https://iradesign.io/) - Creative Tim によるグラデーションイラスト作成ツール。
- [Absurd Design](https://absurd.design/) - ランディングページやアプリ向けのシュールなイラスト。
- [Hero Patterns](https://heropatterns.com/) - 繰り返し使える SVG 背景パターン集。
- [Pattern Monster](https://pattern.monster/) - シームレスな SVG パターンを作るオンラインジェネレーター。
- [Boring Avatars](https://boringavatars.com/) ![GitHub stars](https://img.shields.io/github/stars/boringdesigners/boring-avatars?style=flat&label=%E2%AD%90) ![Release date](https://img.shields.io/badge/release-2025%2F09%2F24-blue?style=flat) ![Last commit](https://img.shields.io/github/last-commit/boringdesigners/boring-avatars?style=flat) - 名前からカラフルな SVG アバターを生成(React ライブラリと API)。 ([GitHub](https://github.com/boringdesigners/boring-avatars))
- [fffuel](https://www.fffuel.co/) - グラデーション、テクスチャ、図形、ノイズなどの SVG ジェネレーター集。
- [Mesh Gradient](https://meshgradient.in/) - メッシュグラデーションを作成・ダウンロード。

- [Leon Sans](https://github.com/cmiscm/leonsans) ![GitHub stars](https://img.shields.io/github/stars/cmiscm/leonsans?style=flat&label=%E2%AD%90) ![Last commit](https://img.shields.io/github/last-commit/cmiscm/leonsans?style=flat) - コードで描画する幾何学的サンセリフ。文字アニメーション向け。
- [Modern Fluid Typography Editor](https://modern-fluid-typography.vercel.app/) - CSS の clamp() で可変フォントサイズを作るエディター。

## カラー

パレット生成、カラーシステム、グラデーション、アクセシビリティ確認。

- [Coolors](https://coolors.co/) - 高速なパレット生成ツール。さまざまな形式でエクスポート可能。
- [Adobe Color](https://color.adobe.com/create) - カラーホイール、配色ルール、アクセシビリティ確認ツール。
- [Color Hunt](https://colorhunt.co/) - コミュニティが選ぶカラーパレット集。
- [Happy Hues](https://www.happyhues.co/) - 実際のサイトレイアウトに当てはめて見られるパレット集。
- [Huetone](https://huetone.ardov.me/) ![GitHub stars](https://img.shields.io/github/stars/ardov/huetone?style=flat&label=%E2%AD%90) ![Last commit](https://img.shields.io/github/last-commit/ardov/huetone?style=flat) - LCH 色空間でアクセシブルなカラーシステムを作成。 ([GitHub](https://github.com/ardov/huetone))
- [Khroma](http://khroma.co/) - 好みの色を学習して配色を提案する AI ツール。
- [UI Colors](https://uicolors.app/create) - 1色から Tailwind CSS 用のカラースケールを生成。
- [InclusiveColors](https://www.inclusivecolors.com/) - WCAG に準拠したアクセシブルなパレットを作成。
- [Huemint](https://huemint.com/) - 機械学習でパレットを生成し、ブランドやサイトのモックで確認できる。
- [ColorBrewer 2.0](https://colorbrewer2.org/) - 地図やデータ可視化向けの配色。
- [WebGradients](https://webgradients.com/) - CSS 線形グラデーションの無料コレクション。
- [Grabient](https://www.grabient.com/) - CSS を出力するグラデーションエディター。
